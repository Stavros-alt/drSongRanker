# drSongRanker

Elo-based ranking for Deltarune, Undertale, Undertale Yellow, and TS!Underswap music. It works. Don't touch the code.

## Features

- Ranks songs using Elo.
- Stats dashboard.
- Global matchups and history for all games.
- Global sync via Supabase.
- MP3 export.
- Mix and Match chapters.
- Regional filters (UTY regions, TS!Underswap areas).
- Volume slider. (Finally.)
- Probability boost for underrated songs.

## Setup

Use a local server.
`python3 -m http.server`

## Exporting Playlists

1.  Click **Export Playlist** -> **Copy Text**.
2.  Use [TuneMyMusic](https://www.tunemymusic.com/transfer) (From Text).
3.  Paste and select destination.

Search strings are optimized for Spotify. If it breaks elsewhere, not my problem.
