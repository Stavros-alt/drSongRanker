# deltarune song ranker

ranks songs. uses elo.

## features

- ranks things.
- plays music.
- saves to localstorage.
- stats page at /stats.html.
- trading cards if you click the list.

## usage

click the one you like.

## dev

1. clone.
2. `python3 -m http.server`.
3. localhost:8000.
