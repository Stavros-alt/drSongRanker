# drSongRanker

Elo-based song ranker for various game soundtracks. It works. Don't touch the code.

## Setup

Use a local server: `python3 -m http.server`

## Exporting Playlists

1. Click **Export Playlist** -> **Copy Text**.
2. Use TuneMyMusic.
